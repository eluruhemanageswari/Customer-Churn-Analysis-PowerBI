# Customer Churn Analysis – Power BI

## Project Overview
This project analyzes customer churn using Microsoft Power BI. The dashboard helps identify customer churn patterns and understand factors that may influence customer retention.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## Key Performance Indicators (KPIs)
- Total Customers
- Churned Customers
- Churn Rate
- Average Monthly Charges

## Dashboard Features
- Churn analysis by Contract Type
- Churn analysis by Internet Service
- Churn analysis by Payment Method
- Churn analysis by Gender
- Churn analysis by Customer Tenure
- Interactive Contract slicer

## Skills Demonstrated
- Data Cleaning and Transformation
- Data Visualization
- DAX Measures
- Exploratory Data Analysis
- Dashboard Development

## Files Included
- `Customer_Churn_Analysis.pbix` – Power BI dashboard
- `Customer_Churn_Analysis_Dataset.csv` – Dataset

## Objective
To analyze customer churn patterns and provide insights that can help businesses improve customer retention.
